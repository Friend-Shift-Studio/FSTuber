# PNGtuber image assets

This directory is reserved for optional, user-provided PNGtuber artwork. FSTuber does not ship sample art. Load PNG, JPG/JPEG, GIF, APNG, or WebP files in the app; filenames containing `idle`, `talk`, or `laugh` are mapped to those built-in states. Custom loop frame names must match loaded image filenames. See the main project README and copied prompt/checklist for OAuth, storage, and export behavior.
